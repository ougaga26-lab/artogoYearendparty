# 藝途發財夢 — ARTOGO 2026 尾牙禮物爭奪大富翁

一台電腦投影棋盤，每個人的手機就是遙控器。不用裝 App、不用在同一個 Wi-Fi。

## 賽前準備（福委）

1. 筆電打開 `https://ougaga26-lab.github.io/artogoYearendparty/`
2. 大廳按「🎁 禮物設定」：輸入每份禮物的等級、名稱，勾選要不要公開，也可以上傳照片（照片只會在結算時出現在大螢幕）
   - 禮物數量要等於正式員工人數
   - 禮物設定存在這台筆電的瀏覽器裡，當天請用同一台電腦、同一個瀏覽器開
3. 每個小遊戲可以先在**小遊戲測試場**試玩：用電腦打開 `https://ougaga26-lab.github.io/artogoYearendparty/test.html`（大廳也有按鈕），再用手機掃右上角的 QR Code，在手機上玩，電腦就會即時轉播。也可以直接在電腦左邊玩
4. 建議先用 2～3 支手機試玩一輪

## 現場怎麼開

1. 筆電接投影機，打開網址，按 F11 全螢幕
2. 大家掃 QR Code，選身分：
   - **正式員工**：開場典禮抽一份禮物，可以搶、也會被搶
   - **試用期**：拿紅包，最終名次決定金額（第 1～3 名 1,000、第 4～6 名 800、第 7 名之後 500）
   - **外賓**：加入「董事會」，不走棋盤
3. 選錯身分的人：在大廳點他的頭像就能切換，滑過去按 × 可以移除
4. 主持人點「主持人手機 QR」用自己的手機掃（不要給玩家看到）
5. 按「開始遊戲！」，進入開場抽獎典禮

## 開場抽獎典禮（約 5～7 分鐘）

1. **搖手機搶順序**：大家在手機按「我準備好了」，全員準備好（或主持人按空白鍵）就倒數 3 秒，接著用力搖手機 10 秒，手機會邊搖邊響、邊震動。搖最多下的人先挑禮物，之後擲骰子也照這個順序
   - 手機偵測不到搖晃時（例如 iPhone 沒允許動作感應），會自動改成狂點螢幕
   - iPhone 不支援震動，聲音要先點過一次畫面才會出來（按「我準備好了」就算）
2. **挑禮物盒**：大螢幕排出一模一樣的禮物盒，正式員工照順序在手機上挑一個號碼（25 秒沒選會自動選）
3. **搖開禮物**：挑完用力搖手機，大螢幕的盒子會跟著越晃越大，搖滿就當場開獎，頭獎有金光和大量彩帶。沒公開名稱的禮物只顯示等級
4. **拆紅包**：試用期同事一樣搖開紅包
5. **開局戰況**：顯示每個人抽到什麼，接著開始擲骰子
- 外賓可以在手機上猜「頭獎在哪一盒」，猜中的人結算時拿到「開場神預言」
- 時間不夠：右下角「跳過典禮，直接隨機分」，主持人手機也有同樣的按鈕

## 遊戲規則

- 起始 200 藝途幣，輪到你時在手機按「擲骰子」
- 經過起點領薪水 50，剛好停在起點再加 50
- **事件格**只顯示類別（語音導覽、官網・伺服器、DAINY…），踩到才知道是好事還是壞事
- 遇到壞事可以選：認了／用免死金牌／**挑戰小遊戲**（過關就免罰）
- **🎁 搶禮物格**：付錢和任何人交換禮物，價格依等級（頭獎 150、二獎 100、三獎 60、普獎 30），錢付給被搶的人
  - 每份禮物被搶 2 次後鎖定
  - 被搶的人如果有「防盜鎖」，會自動擋下來
  - 試用期玩家踩到時改當「禮物仲介」：免費讓兩個人互換禮物，抽 30 幣
- **⚔️ PK 格**（共 5 格）：指定一個人對決，再選賭注：🎁 賭禮物（兩人都是正式員工才有，贏的可以換禮物）、💰 賭 50 幣或 100 幣
  - 接著翻 3 張遊戲卡（至少 1 張動身體的），發起的人挑一個項目
  - 被挑戰的人可以花 20 幣（付給發起的人）把項目換成另外兩張其中一張
  - **🦸 代打卡**（機會卡、命運卡抽得到）：PK 開始前可以請任何人替你上場，同事或外賓都可以。代打贏了，同事拿 10 幣代打費
- **👀 偷看格**：在自己手機上偷看任一份禮物的內容
- **命運格**：由一位外賓從 3 張蓋著的牌挑一張
- 最後一輪結束後是**首富特權**：第 1～3 名（正式員工）各可以免費換一份沒鎖定的禮物
- 最後全場一起**拆禮物**（大螢幕點卡片翻開）

### 外賓（董事會）
- 幫踩到命運格的人挑牌
- 表演時打賞：狂按手機，每下 +1 幣，每位董事最多 20 幣
- 投票：例如「現場 Demo」好不好
- 真人 PK 兩人說法不一樣時，由董事會投票
- 押寶誰最後抱走頭獎（最後一輪開始後鎖定），押中的人結算時獲得「最強董事」

### 小遊戲（程式判定，不需要裁判）
色卡對色、速算、找 Bug／找錯字、打字、狂點、反應力（有老闆假動作）、精準計時、對齊、記憶、人流估算（4 選 1）。

手機當裁判的 PK：
- **🦩 金雞獨立**：手機握在胸前單腳站，手機晃太大就出局。15 秒後要閉眼、30 秒後摸鼻子、45 秒後踮腳尖，最多 60 秒
- **📱 搖手機耐力賽**：60 秒比誰搖得多

真人 PK：比腕力、柔軟度，比完兩人在手機上按誰贏。

玩小遊戲時，大螢幕會**即時轉播**玩家手機上的進度（PK 時左右分割）。精準計時不顯示秒數、記憶不顯示答案、找 Bug 不顯示位置，避免台下場外支援。真人 PK 會顯示大大的 VS 對戰畫面。

## 主持人小抄

| 狀況 | 大螢幕 | 主持人手機 |
|---|---|---|
| 有人手機沒反應，幫他擲 | `空白鍵`／代擲骰子 | 代擲骰子 |
| 有人該選卻沒選 | 卡片上的小按鈕可以代選 | 代選 |
| 小遊戲或真人 PK 卡住 | 「提早結束」／按誰贏 | 提早結束／按誰贏 |
| 整個卡住，直接換下一位 | `N` | 跳到下一位 |
| 臨場加碼／扣錢 | — | 手動加扣錢 |

- 輪到的人 45 秒沒擲會自動擲；要選的東西大多 40 秒沒選會自動選
- 主畫面不小心重新整理：大廳會出現「繼續上一局」
- 9 位玩家 × 5 輪大約 40～50 分鐘，加上首富特權和拆禮物約 1 小時；大廳可以調輪數

## 想改內容

所有事件、卡片、小遊戲門檻、禮物價格、紅包金額都在 [`assets/game-data.js`](assets/game-data.js)，檔案開頭有寫法說明。改完推到 GitHub，一兩分鐘後網站會更新。

## 技術說明

- 純靜態網頁：`index.html` 主畫面、`play.html` 手機、`assets/games.js` 小遊戲
- 連線走公開 MQTT 伺服器（EMQX，備用 HiveMQ），在大廳可以切換。用房號區隔，每局換新房號
- 遊戲狀態由主畫面掌控。沒公開的禮物名稱不會傳到手機，偷看結果只私下傳給偷看的人
- 本機測試：在資料夾執行 `python -m http.server`，打開 `http://localhost:8000`。手機分頁網址加 `&t=1`、`&t=2`，就能在同一台電腦模擬多支手機

## 更新程式後

GitHub 網頁會被瀏覽器快取 10 分鐘。每次改程式，請把 `assets/game-data.js` 第一行的 `APP_VER` 改成新的版本號，並把三個 html 裡 `?v=` 後面的數字一起改掉。這樣主畫面的 QR Code 會帶新版本號，手機如果抓到舊版也會跳出「請重新整理」的提示。主畫面的電腦請按 `Ctrl + F5` 強制重新整理。
