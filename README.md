# 藝途發財夢 — ARTOGO 2026 尾牙大富翁

一台電腦投影棋盤，每個人的手機就是遙控器。不用裝 App、不用在同一個 Wi-Fi。

## 現場怎麼開

1. 筆電接投影機，打開 `https://ougaga26-lab.github.io/artogoYearendparty/`（主畫面），按 F11 全螢幕
2. 大家用手機相機掃大螢幕上的 QR Code → 輸入名字、選角色（同仁／外賓／啦啦隊）、挑動物
3. 主持人點「主持人手機 QR」，用自己的手機掃 → 拿到主持人控制台（**不要給玩家看到**）
4. 人到齊後按「開始遊戲！」（順序會隨機）

## 遊戲規則

- 起始 200 藝途幣，輪到你時在手機按「擲骰子」（或搖一搖）
- 經過起點領薪水 50，剛好停在起點再加 50
- 設定的輪數（預設 5 輪）結束時，**藝途幣最多的人是發財王**
- 結算時另外頒：表演之星（挑戰成功最多）、最衰同事（踩到最多麻煩）、環島達人（繞最多圈）

### 遇到壞事怎麼辦？
手機上會跳出選項：
- **認了**：乖乖接受懲罰
- **🛡️ 免死金牌**：直接抵銷（抽機會卡拿到）
- **🎤 點唱券**：高歌一曲，呼隆過去，主持人判定通過就解除
- **🔥 現場救援**：隨機一個挑戰（在地上滾 5 圈、深蹲喊口號…），成功就解除，**失敗懲罰加倍**

### 外賓怎麼參與
- 選「外賓」就跟同事一樣下場玩，排行榜上會標「外賓」
- 「貴賓交流」格：踩到的人要找一位外賓一起做雙人挑戰，成功兩人都加錢
- 不想下場的人選「啦啦隊」：狂按手機上的加油鍵，每 10 下幫正在玩的人 +1 幣（每回合最多 +10）
- 遊戲中途也能掃碼加入，從起點出發

## 主持人小抄

| 狀況 | 大螢幕鍵盤 | 主持人手機 |
|---|---|---|
| 判定挑戰成功／失敗 | `1` / `2` | 按綠色／白色按鈕 |
| 有人手機沒反應，幫他擲 | `空白鍵` | 代擲骰子 |
| 卡住了，直接換下一位 | `N` | 跳到下一位 |
| 臨場加碼／扣錢 | — | 手動加扣錢 |

- 輪到的人 45 秒沒擲，會自動幫他擲
- 手機上要選的東西（救援、偷誰的錢）40 秒沒選，會自動選預設
- 主畫面不小心重新整理也沒關係：大廳會出現「繼續上一局」
- 15 人 × 5 輪大約 40～60 分鐘，時間不夠可在大廳調輪數，或隨時按「結束遊戲」直接結算

## 想改內容

所有格子、機會卡、命運卡、真人挑戰都在 [`assets/game-data.js`](assets/game-data.js)，用記事本就能改，檔案開頭有寫法說明。改完推到 GitHub，一兩分鐘後網站就會更新。

## 技術說明

- 純靜態網頁（`index.html` 主畫面、`play.html` 手機），放在 GitHub Pages
- 連線走公開 MQTT 伺服器（EMQX，備用 HiveMQ），在大廳可以切換。用房號區隔，每局換新房號
- 遊戲狀態由主畫面掌控，手機只送指令
- 本機測試：在資料夾執行 `python -m http.server`，開 `http://localhost:8000`；手機分頁網址加 `&t=1`、`&t=2` 可以在同一台電腦模擬多支手機
