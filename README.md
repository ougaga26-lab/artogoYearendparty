# 藝途發財夢 — ARTOGO 2026 尾牙禮物爭奪大富翁

一台電腦投影棋盤，每個人的手機就是遙控器。不用裝 App、不用在同一個 Wi-Fi。

## 賽前準備（福委）

1. 筆電打開 `https://ougaga26-lab.github.io/artogoYearendparty/`
2. 大廳按「🎁 禮物設定」：輸入每份禮物的等級、名稱，勾選要不要公開，也可以上傳照片（照片只會在結算時出現在大螢幕）
   - 禮物數量要等於正式員工人數
   - 禮物設定存在這台筆電的瀏覽器裡，當天請用同一台電腦、同一個瀏覽器開
3. 建議先用 2～3 支手機試玩一輪

## 現場怎麼開

1. 筆電接投影機，打開網址，按 F11 全螢幕
2. 大家掃 QR Code，選身分：
   - **正式員工**：開場隨機分到一份禮物，可以搶、也會被搶
   - **試用期**：拿紅包，最終名次決定金額（第 1～3 名 1,000、第 4～6 名 800、第 7 名之後 500）
   - **外賓**：加入「董事會」，不走棋盤
3. 選錯身分的人：在大廳點他的頭像就能切換，滑過去按 × 可以移除
4. 主持人點「主持人手機 QR」用自己的手機掃（不要給玩家看到）
5. 按「開始遊戲！」

## 遊戲規則

- 起始 200 藝途幣，輪到你時在手機按「擲骰子」
- 經過起點領薪水 50，剛好停在起點再加 50
- **事件格**只顯示類別（語音導覽、官網・伺服器、DAINY…），踩到才知道是好事還是壞事
- 遇到壞事可以選：認了／用免死金牌／**挑戰小遊戲**（過關就免罰）
- **🎁 搶禮物格**：付錢和任何人交換禮物，價格依等級（頭獎 150、二獎 100、三獎 60、普獎 30），錢付給被搶的人
  - 每份禮物被搶 2 次後鎖定
  - 被搶的人如果有「防盜鎖」，會自動擋下來
  - 試用期玩家踩到時改當「禮物仲介」：免費讓兩個人互換禮物，抽 30 幣
- **⚔️ PK 格**：指定一個人對決，可能是手機小遊戲或真人對決（比腕力、柔軟度…）。正式員工之間贏的人可以換禮物；有試用期玩家參與時，贏的人拿 50 幣
- **👀 偷看格**：在自己手機上偷看任一份禮物的內容
- **命運格**：由一位外賓從 3 張蓋著的牌挑一張
- 最後一輪結束後是**首富特權**：第 1～3 名（正式員工）各可以免費換一份沒鎖定的禮物
- 最後全場一起**拆禮物**（大螢幕點卡片翻開）

### 外賓（董事會）
- 幫踩到命運格的人挑牌
- 表演時打賞：狂按手機，每下 +1 幣，每位董事最多 20 幣
- 投票：例如「現場 Demo」好不好
- 真人 PK 兩人說法不一樣時，由董事會投票
- 押寶誰最後抱走頭獎（最後一輪開始後鎖定），押中的人結算時獲得「最強董事」

### 小遊戲（程式判定，不需要裁判）
色卡對色、速算、找 Bug／找錯字、打字、狂點、反應力、精準計時、對齊、記憶、人流估算。真人 PK 有比腕力、柔軟度、單腳站立、不眨眼、猜拳，比完兩人在手機上按誰贏。

## 主持人小抄

| 狀況 | 大螢幕 | 主持人手機 |
|---|---|---|
| 有人手機沒反應，幫他擲 | `空白鍵`／代擲骰子 | 代擲骰子 |
| 有人該選卻沒選 | 卡片上的小按鈕可以代選 | 代選 |
| 小遊戲或真人 PK 卡住 | 「提早結束」／按誰贏 | 提早結束／按誰贏 |
| 整個卡住，直接換下一位 | `N` | 跳到下一位 |
| 臨場加碼／扣錢 | — | 手動加扣錢 |

- 輪到的人 45 秒沒擲會自動擲；要選的東西大多 40 秒沒選會自動選
- 主畫面不小心重新整理：大廳會出現「繼續上一局」
- 9 位玩家 × 5 輪大約 40～50 分鐘，加上首富特權和拆禮物約 1 小時；大廳可以調輪數

## 技術說明

- 純靜態網頁：`index.html` 主畫面、`play.html` 手機、`assets/games.js` 小遊戲
- 連線走公開 MQTT 伺服器（EMQX，備用 HiveMQ），在大廳可以切換。用房號區隔，每局換新房號
- 遊戲狀態由主畫面掌控。沒公開的禮物名稱不會傳到手機，偷看結果只私下傳給偷看的人
- 本機測試：在資料夾執行 `python -m http.server`，打開 `http://localhost:8000`。手機分頁網址加 `&t=1`、`&t=2`，就能在同一台電腦模擬多支手機
